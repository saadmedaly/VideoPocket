# VideoPocket

منصة ويب عربية (RTL) لتنزيل فيديوهات يوتيوب العامة بصيغة MP4 (صوت + صورة) على الهاتف، عبر الشبكة المحلية.

**للاستخدام الشخصي فقط** بفيديوهات تملكها أو لديك إذن بتنزيلها. لا يتجاوز هذا المشروع أي حماية DRM أو قيود وصول أو محتوى خاص/مدفوع.

## البنية

```
backend/    FastAPI + yt-dlp + FFmpeg — خادم التحليل والتنزيل (طابور + عامل خلفي + SQLite)
frontend/   صفحة HTML/CSS/JS عربية RTL بسيطة
proxy/      reverse proxy بسيط (FastAPI + httpx) يجمع الواجهة والـAPI تحت origin واحد
start-public.bat   سكريبت تشغيل تلقائي بأمر واحد: خادم + بروكسي + رابط عام عبر Cloudflare Tunnel
```

الواجهة لا تعرف عنوان الخادم الحقيقي؛ هي تستخدم مسارات نسبية (`/api/...`) فقط، لذلك تعمل بلا تعديل سواء خُدِمت محليًا عبر البروكسي أو عبر الرابط العام.

## التشغيل بأمر واحد (رابط عام على الإنترنت)

هذا هو المسار الموصى به — رابط HTTPS عام (`https://xxxxx.trycloudflare.com`) يمكن إرساله لأي شخص خارج شبكتك.

### المتطلبات
- Python 3.11+ على PATH
- FFmpeg و ffprobe على PATH
- `cloudflared` (مجاني، بدون حساب) — إن لم يكن مثبّتًا: `winget install --id Cloudflare.cloudflared -e`

### الإعداد لمرة واحدة

```powershell
cd backend
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
cd ..\proxy
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### التشغيل

شغّل من جذر المشروع:

```
start-public.bat
```

يقوم تلقائيًا بـ: تشغيل الخادم على المنفذ 8200 ← تشغيل البروكسي على 8090 (يجمع الواجهة + API تحت origin واحد) ← الانتظار حتى الجاهزية ← تشغيل Cloudflare Quick Tunnel ← استخراج الرابط العام وطباعته:

```
VideoPocket is LIVE:
https://xxxxx.trycloudflare.com
```

أرسل هذا الرابط لأي شخص؛ سيعمل من أي مكان في العالم ما دام حاسوبك والسكريبت يعملان.

### الإيقاف

اضغط أي مفتاح في نافذة السكريبت — سيوقف الخادم والبروكسي والـtunnel تلقائيًا وينظّف العمليات التي بدأها فقط (لا يلمس عمليات أخرى على جهازك).

### ملاحظات حول Quick Tunnel المجاني

- الرابط **عشوائي ومؤقت** — يتغيّر كل مرة تُشغّل السكريبت (هذه خاصية "quick tunnel" المجاني بلا حساب Cloudflare؛ رابط ثابت يتطلب domain وحساب، وهو خارج نطاق "مجاني بالكامل بدون أي تسجيل").
- لا رابط بعد إغلاق السكريبت أو إيقاف الحاسوب — الخدمة تعمل فقط أثناء تشغيلهما.
- لا بطاقة بنكية ولا حساب Cloudflare مطلوب لهذا النوع من الأنفاق.

## التشغيل المحلي البديل (بدون رابط عام، عبر البروكسي فقط)

```powershell
cd backend
.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8200
```

وفي نافذة أخرى:

```powershell
cd proxy
.venv\Scripts\python.exe -m uvicorn proxy:app --host 0.0.0.0 --port 8090
```

ثم افتح `http://127.0.0.1:8090` محليًا، أو `http://<عنوان-جهازك-على-الشبكة>:8090` من الهاتف على نفس شبكة Wi-Fi (اعرف عنوانك بـ `ipconfig`، بطاقة Wi-Fi النشطة فقط، تجاهل عناوين VirtualBox/VMware الافتراضية).

**ملاحظة:** الواجهة تعتمد على البروكسي الآن (مسارات `/api/*` نسبية)؛ تشغيل `frontend/` بخادم ثابت منفصل عن البروكسي لن يصل إلى الـAPI.

## متغيرات البيئة (Backend)

انظر `backend/.env.example` للقائمة الكاملة. الأهم:

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `ALLOWED_ORIGINS` | قائمة الأصول المسموح لها بالاتصال (CORS) | `http://127.0.0.1:5500,http://localhost:5500` |
| `PORT` | منفذ الخادم | `8200` |
| `ACCESS_TOKEN` | رمز دخول اختياري لحماية الخدمة عند نشرها على الإنترنت | (فارغ) |
| `MAX_VIDEO_DURATION` | أقصى مدة فيديو مسموح بها (ثوانٍ) | `10800` (3 ساعات) |
| `MAX_DOWNLOAD_SIZE` | أقصى حجم ملف نهائي (بايت) | `1610612736` (1.5 ج.ب) |
| `DOWNLOAD_TIMEOUT` | أقصى مدة لعملية تنزيل واحدة (ثوانٍ) | `2700` (45 دقيقة) |
| `FILE_RETENTION_SECONDS` | مدة صلاحية الملف الجاهز قبل حذفه | `3600` (ساعة) |
| `DOWNLOAD_WORKERS` | عدد عمليات التنزيل المتزامنة | `1` |

هذه القيم افتراضات معقولة لجهاز شخصي عادي؛ عدّلها حسب موارد جهازك الفعلية.

## كيف يعمل تنزيل الفيديوهات الطويلة

- الطلب يُنشئ "مهمة" (job) في قاعدة بيانات SQLite محلية، ويعود فورًا برقم تعريف المهمة.
- عامل خلفي واحد (قابل للزيادة عبر `DOWNLOAD_WORKERS`) يسحب المهام من طابور ويعالجها بالتتابع.
- yt-dlp ينزّل إلى القرص تدريجيًا (لا يُحمَّل الفيديو في الذاكرة)، ثم يدمج الصوت والصورة بصيغة MP4 عبر FFmpeg على الخادم.
- الواجهة تستطلع حالة المهمة كل 1.5 ثانية وتعرض: الانتظار، جلب المعلومات، التنزيل (مع النسبة والسرعة والوقت المتبقي الفعليين من yt-dlp)، الدمج، جاهز، فشل، أُلغي.
- بعد إعادة تشغيل الخادم، أي مهمة كانت منقطعة أثناء المعالجة تُعلَّم تلقائيًا بأنها "فشل" (`interrupted_by_restart`) بدل أن تبقى معلّقة إلى الأبد.
- الملفات الجاهزة تُحذف تلقائيًا بعد ساعة (قابل للتعديل)، وكذلك أي مجلدات متبقية من مهام فاشلة أو ملغاة أو من عمليات متوقفة بشكل غير متوقع.

## القيود الحالية

- **دعم يوتيوب فقط.** لا TikTok ولا Instagram ولا منصات أخرى في هذه النسخة.
- **فيديو واحد فقط لكل رابط** — لا قوائم تشغيل، لا بث مباشر جارٍ، لا محتوى خاص.
- **لا حدّ تعسفي بـ 30 دقيقة**، لكن الحد العملي (3 ساعات / 1.5 ج.ب افتراضيًا) قابل للتعديل حسب موارد جهازك عبر متغيرات البيئة أعلاه — فيديو طويل جدًا جدًا (مثل بث كامل لعدة ساعات) قد يحتاج رفع هذه القيم ومساحة قرص كافية.
- **عامل تنزيل واحد افتراضيًا** — تنزيلان طويلان متزامنان سيُعالَجان بالتتابع، لا بالتوازي (قابل للتغيير عبر `DOWNLOAD_WORKERS` لكن هذا يستهلك نطاقًا ترددًا ومعالجة أكبر).
- **الوصول العام عبر Cloudflare Quick Tunnel مرهون بتشغيل حاسوبك** — ليس نشرًا سحابيًا دائمًا؛ الرابط يتوقف إذا أوقفت السكريبت أو أغلقت الحاسوب، ويتغيّر مع كل تشغيل جديد.
- **لا دعم لنقل مستمر في الخلفية**: إذا أُغلق المتصفح أثناء نقل الملف نفسه (بعد الضغط على "حفظ الفيديو")، ينقطع النقل؛ أما تقدّم التنزيل على الخادم فمستمر بشكل مستقل ولا يتأثر بإغلاق المتصفح قبل جاهزية الملف.
- **الصيغة النهائية mp4** مع ترميز الفيديو والصوت كما يوفرهما يوتيوب (av1/vp9 + aac غالبًا) عبر دمج stream copy فقط (`ffmpeg -c copy`، لا إعادة ترميز) — سرعة أعلى واستهلاك معالجة أقل، والملف يعمل على مشغلات الهاتف الحديثة.
- **الجودة الافتراضية 720p** (وليس 1080p) لتسريع التنزيل والرفع للعميل عبر الرابط العام وتقليل استهلاك المساحة والذاكرة؛ 1080p يبقى متاحًا كخيار يدوي عند توفره.
- **رابط عام مؤقت وعشوائي** عبر Cloudflare Quick Tunnel — غير مناسب لإعلان دائم؛ لرابط ثابت دائم يلزم حساب Cloudflare ودومين، وهذا خارج نطاق "مجاني بدون تسجيل" المطلوب هنا.

## لماذا Cloudflare Tunnel وليس Render/Railway/Vercel

لم يُنشر الخادم الفعلي (الذي يتصل بيوتيوب ويحمّل الفيديوهات) على أي من Render أو Railway أو Vercel. السبب العملي المعروف من مشروع مشابه في هذا الجهاز (Video-Saver): مزودات الاستضافة المجانية الشائعة (خصوصًا Render) تُحجب أحيانًا من طرف يوتيوب كمحاولات بوت `Sign in to confirm you're not a bot` بسبب نطاقات IP الخاصة بمراكز البيانات، وهذه مشكلة من طرف يوتيوب لا تُحل بأدوات تجاوز (لم أستخدم أي كوكيز أو بروكسي أو خدمة تجاوز).

الحل المعتمد هنا: الخادم الفعلي يبقى يعمل على **حاسوبك** (عنوان منزلي عادي، لا يُحجب)، وCloudflare Tunnel (مجاني، بدون حساب، Quick Tunnel) يفتح له رابطًا عامًا بصيغة `https://xxxxx.trycloudflare.com` دون الحاجة لفتح منافذ الراوتر أو كشف عنوان IP الحقيقي لجهازك. هذا تم اختباره فعليًا بنجاح عبر الرابط العام (انظر نتائج الاختبار أدناه)، ولا يزال الخادم والتنزيل من نفس عنوان IP المنزلي الذي ينجح محليًا دائمًا.

**تنبيه مهم:** هذا ليس استضافة سحابية دائمة. الخدمة تتوقف إذا أوقفت `start-public.bat` أو أُغلق الحاسوب أو انقطع اتصاله بالإنترنت.

## تأكيد

لم يتم تفعيل أي خدمة مدفوعة أو اشتراك أو بطاقة بنكية في أي جزء من هذا العمل. كل المكتبات المستخدمة (FastAPI، yt-dlp، FFmpeg) مجانية ومفتوحة المصدر، والتشغيل محلي بالكامل.
